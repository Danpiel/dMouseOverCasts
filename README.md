# dMouseOverCasts

Аддон для World of Warcraft, который собирает макросы по маусоверу. В настройках вы выбираете заклинания и опции, аддон пишет обычный игровой макрос, и вы перетаскиваете его на панель команд. Если под курсором союзник (в мире, на неймплейте или на рамке группы/рейда), макрос колдует помогающее заклинание, если враг — атакующее. Клавиши и назначения аддон не трогает.

Поддерживаемые клиенты:

| Клиент | Interface |
|---|---|
| World of Warcraft: Forever | 16001 |
| Retail (Midnight) | 120100, 120105 |

## Установка

Папка аддона должна называться **`dMouseOverCasts`**: `World of Warcraft\_forever_\Interface\AddOns\dMouseOverCasts\dMouseOverCasts.toc` (для retail — `_retail_`; Forever из клиента Battle.net ставится в `_classic_beta_`). `README.md` и `tests` в игре не нужны, но и не мешают.

## Как пользоваться

**Esc → Настройки → Модификации (AddOns) → dMouseOverCasts**, или `/dmo`.

1. **Новый макрос.**
2. Впишите **помогающее** заклинание (союзник под мышкой) и/или **атакующее** (враг под мышкой). Начните печатать название — под полем появится список подходящих заклинаний из вашей книги; стрелка справа от поля открывает всю книгу. Сначала идут заклинания, подходящие полю (для союзников или для врагов), остальные ниже и серым. Вверх/вниз — выбор, Enter берёт подсвеченное заклинание, Tab — подсвеченное или первое, клик — любое; Esc или клик мимо списка закрывают его. Ещё можно ввести ID, перетащить заклинание из книги на иконку рядом с полем или вставить shift-кликом. Подходят и предметы (камень здоровья): название, которого нет в книге, остаётся как введено. Чтобы взять конкретный ранг, напишите `Малое исцеление(Уровень 2)` или выберите его в списке: младшие ранги появляются под заклинанием, когда его название введено целиком. Без ранга используется высший.
3. Перетащите большую иконку макроса на панель команд (или нажмите «Взять макрос» и кликните по ячейке панели).

Макрос появляется в окне макросов игры (`/macro`) сразу, как только выбрано первое заклинание. Дальше аддон обновляет его при каждом изменении, а на панели он остаётся на месте.

Кнопка на панели показывает заклинание, которое сейчас сработает: помогающее, когда под мышкой союзник, атакующее, когда враг. Для этого нужны строка `#showtooltip` и иконка «?» у самого макроса; аддон ставит её при каждой записи. Если выбрать в окне макросов другую иконку, кнопка будет показывать только её, пока аддон не запишет макрос заново.

Опции:

- **Название макроса.** По умолчанию это название заклинания; можно задать своё, до 16 букв. Чужие макросы аддон не трогает: если имя занято, он добавит номер («Быстрое исцеление 2»).
- **Где хранить:** макросы персонажа или общие (для всех персонажей). При переносе макрос создаётся заново, и его нужно снова поставить на панель.
- **Под мышкой никого подходящего:** колдовать на текущую цель или ничего не делать. Вражеская цель получает атакующее заклинание, дружественная — помогающее.
- **Иначе помогающее — на себя:** последний вариант, если не подошло ничего другое. Вместе с «колдовать на текущую цель» это обычное применение заклинания, как с его собственной кнопки: на дружественную цель, иначе на себя. На себя его направляет игра (настройка автоприменения к себе, по умолчанию включена). С «ничего не делать» в макросе стоит явное `[@player]`.
- **Пропускать мёртвых.** Выключите для воскрешения.
- **Править макрос вручную.** Сгенерированный текст становится обычным: можно дописать `[@cursor]`, `/stopcasting` и т. п.

Например, «Быстрое исцеление» + «Кара» со всеми опциями дают:

```
#showtooltip
/cast [@mouseover,help,nodead]Быстрое исцеление;[@mouseover,harm,nodead][harm,nodead]Кара;Быстрое исцеление
```

Слева направо: союзник под мышкой; враг под мышкой или вражеская цель; иначе обычное применение помогающего заклинания.

У игрового макроса лимит 255 байт, а русская буква занимает два. Поэтому каждое название пишется как можно меньше раз: помогающее заклинание дважды, атакующее один раз. Счётчик под текстом показывает длину. Если макрос всё равно не влезает, выберите «ничего не делать»: тогда оба названия пишутся по одному разу.

В бою игра запрещает создавать и менять макросы. Изменения, сделанные в бою, запишутся сразу после него.

Список макросов хранится отдельно для каждого персонажа. Кнопка «Удалить» убирает макрос и из списка аддона, и из макросов игры, а значит, и с панелей.

## Команды

| Команда | Действие |
|---|---|
| `/dmo` | открыть настройки |
| `/dmo list` | показать макросы в чате |

## Файлы

| Файл | Назначение |
|---|---|
| `Core.lua` | старт, слэш-команды, поиск заклинаний |
| `Spellbook.lua` | список заклинаний из книги и поиск по нему |
| `Macro.lua` | сборка текста макроса |
| `Profile.lua` | SavedVariables, список макросов персонажа |
| `Macros.lua` | создание, обновление и удаление игровых макросов |
| `Options.lua` | страница в настройках игры |
| `Locales.lua` | английский и русский тексты |

## Тесты

`tests/` — мок WoW API и тесты, которые запускают аддон в обычном Lua 5.1 (через Python-пакет `lupa`): генерация макросов и то, что они колдуют по союзнику, врагу и цели, запись игровых макросов и их иконка, бой, страница настроек, список заклинаний из книги, перенос настроек и макросов прежних версий.

```bash
python -m pip install lupa
python tests/run.py .
```
